# ServiceHub

ServiceHub is a Spring Boot service-booking website with Thymeleaf pages, MySQL persistence, BCrypt password hashing, and session-based authentication.

## Run locally

Requirements: Java 17+, Maven 3.9+, and MySQL 8+.

Create the database with `CREATE DATABASE servicehub_db;`, then run `mvn spring-boot:run`.

Open http://localhost:8082.

Default admin: `admin@servicehub.local` / `Admin@12345`.
